# Google

Clone simples da página inicial do Google usando HTML e CSS.

## Descrição

Este projeto recria a interface da página inicial do Google com foco em layout responsivo e estilo visual semelhante ao original. Ele incorpora ícones do Material Icons e utiliza CSS customizado para posicionar o cabeçalho, o logo, o campo de busca e os botões.

## Tecnologias

- HTML5
- CSS3
- Material Icons

## Estrutura do projeto

- `index.html` — página principal do clone do Google
- `assets/css/style.css` — estilos do projeto

## Como usar

1. Abra o arquivo `index.html` no seu navegador.
2. O projeto não requer servidor nem instalação adicional.

## Observações

- O projeto é uma recriação visual e não implementa a funcionalidade de busca real.
- O logo do Google é carregado diretamente do site oficial via URL.
